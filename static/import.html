1. Choose your spreadsheet

Save your existing register as a CSV file first. In Excel, choose File → Save As and pick CSV UTF-8. In Google Sheets, choose File → Download → CSV.

What can the file contain?

Your column names don't need to match ours: we recognise common ones like "Badge No", "Surname", "VRM" or "MOT due", and you can correct anything we get wrong. Title rows above the headers, blank rows, UK dates such as 31/03/2027 or 1st March 2027, and short licence types like "PH" or "HC" are all fine.
